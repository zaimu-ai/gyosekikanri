# 業績管理

預金明細・通帳・仕訳帳・総勘定元帳・試算表・決算書を取り込み、予実管理（PL）・勘定科目別の明細と内訳分析・資金繰り表・KPIを、ひとつの画面で管理するブラウザアプリです。
`index.html` の1ファイルだけで動き、サーバーやインストールは不要です。

## 使い方

1. `index.html` をブラウザ（Chrome / Edge / Safari）で開きます。
2. 初回は「サンプルで試す」か「空の状態から始める」を選びます。
3. 入力した内容は自動で保存されます。保存ボタンはありません。

## 画面

| 画面 | できること |
|---|---|
| ダッシュボード | 売上・粗利・営業利益・経常利益の予算比／前年比、現預金残高、予算超過の科目、KPIの一覧 |
| 予実管理（PL） | 単月／期首からの累計／通期で、予算・実績・差異・達成率・売上高比・前年比を表示。通期は「着地見込（実績＋残りの月の予算）」も表示。月次推移表、グラフ、CSV出力 |
| 科目別明細・内訳 | 明細の追加・修正・削除（削除は元に戻せる）、勘定科目別・取引先別の内訳と前年同期間比較、CSV取込・出力 |
| 資金繰り表 | 経常収支・財務収支・月末残高。月ごとに実績／予定を切り替え。予算・実績からの下書き作成、警戒ラインを下回る月の警告 |
| KPI | 月ごとの目標と実績、達成率、前年比。集計方法（合計・平均・最新値）と評価の向き（多い／少ないほど良い）を設定可能 |
| 財務分析 | 収益性（経営資本営業利益率、総資本事業利益率とその分解、ROE、各回転率）・安全性（流動比率〜有利子負債返済年数）の指標、キャッシュ・フロー計算書（間接法）、要約貸借対照表と科目の分類 |
| データ取込 | 預金明細・通帳・仕訳帳・総勘定元帳・試算表・推移表・決算書を取り込み（CSV・PDF）。資金繰りの分類の確認と修正、覚えた分類の管理、取込履歴の取消 |
| 設定・データ（右上の歯車） | 会社名、期首月、表示単位（円／千円）、税区分表示、予算入力（前年実績×%で一括作成、Excelから12か月分の貼り付け）、勘定科目、バックアップ |

## データ取込

| データ | 形式 | 使いみち |
|---|---|---|
| 預金明細・通帳 | CSV、文字入りPDF（スキャンPDF・写真は claude.ai で開いたときのみAI読み取り） | 資金繰りの実績（入出金）、期首残高、月末残高の照合 |
| 仕訳帳 | CSV（マネーフォワード・freee形式、弥生の見出しなし形式など）、文字入りPDF | 損益の実績明細、現金・預金の相手科目から資金繰りの実績 |
| 総勘定元帳 | CSV、文字入りPDF | 同上（同じ月に仕訳帳がある場合は仕訳帳を優先） |
| 試算表・月次推移表 | CSV、文字入りPDF | 明細のない月の損益実績、資金繰りの推計、月末残高の照合 |
| 決算書 | 文字入りPDF、CSV | 前年の通期実績（比較・予算作成）、翌年度の期首残高 |

- 見出しの名前から列を自動で判定します。ずれている場合は確認画面の「列の割り当て」で直せます。
- 取込前に確認画面で、件数・期間・合計、残高の整合（前の残高＋入金−出金＝残高）、借方・貸方の一致、決算書の利益の検算を表示します。
- 取り込むたびに、その前の状態を端末内にバックアップします。取込は履歴からまとめて取り消せます。
- Excel（.xlsx）は直接読めません。CSVで保存してから取り込んでください。

### 資金繰り表の自動作成

- 実績の月：取込データから自動で作ります。元データは月ごとに **預金明細 → 仕訳帳 → 総勘定元帳 → 試算表（推計）** の順で、より詳しいものを使います（預金明細がある月は、仕訳の「現金」だけを足します）。
- 分類：預金明細は摘要（標準ルール＋覚えた分類）、仕訳・元帳は相手科目で、売掛金回収・買掛金支払・人件費・諸経費・税金・借入・返済・設備投資などに分けます。分類できないものは「未分類」として表示します。分類を直すと、同じ摘要（相手科目）に適用し、次回から自動で分類します。
- 試算表からの推計：売掛金の貸方＝回収、買掛金の借方＝支払、借入金の借方／貸方＝返済／借入、人件費・支払利息は損益の金額、残りを諸経費・その他入金とします（推計と表示）。
- 期首残高：手入力 → 試算表の期首残高 → 前期決算書の現金及び預金 → 通帳の残高 → 前年度末 の順で使います。
- 照合：通帳・試算表の月末残高と、資金繰り表の月末残高の差額を表示します。
- 予定の月：これまでどおり予算・実績から下書きし、自由に修正できます。

## 財務分析

元データは「決算書（年度末）」か「試算表（月末時点）」を選べます。期首の貸借対照表は、前期の決算書 → 試算表の期首（前月）残高の順で使います。

| 指標 | 計算式 |
|---|---|
| 経営資本営業利益率 | 営業利益 ÷ 経営資本（総資産−建設仮勘定−投資その他の資産−繰延資産） |
| 総資本事業利益率 | （営業利益＋受取利息・配当金）÷ 総資本 |
| └ 総資本経常利益率 | 経常利益 ÷ 総資本（＝売上高経常利益率×総資本回転率） |
| └ 総資本利払前経常利益率 | （経常利益＋支払利息・割引料）÷ 総資本 |
| 自己資本純利益率 | 当期純利益 ÷ 自己資本（純資産） |
| 売上債権・棚卸資産・有形固定資産・買入債務回転率 | 売上高 ÷ 各資産・負債（回転期間も表示） |
| 流動比率／当座比率 | 流動資産／当座資産（現金預金＋売上債権＋有価証券）÷ 流動負債 |
| 手元流動性 | 現金預金＋有価証券（月商の何か月分かも表示） |
| 自己資本比率／負債比率 | 自己資本 ÷ 総資本／負債 ÷ 自己資本 |
| 固定比率／固定長期適合比率 | 固定資産 ÷ 自己資本／固定資産 ÷（自己資本＋固定負債） |
| インタレスト・カバレッジ・レシオ | （営業利益＋受取利息・配当金）÷ 支払利息・割引料 |
| 設備投資対営業CF比率 | 設備投資額 ÷ 営業キャッシュ・フロー |
| 有利子負債返済年数 | 有利子負債（借入金・社債・リース債務）÷ 営業キャッシュ・フロー |

- 収益性・回転率は、期首と期末の平均（選択で期末の額）を使います。安全性は期末の額です。
- 試算表（期中）の場合、損益・キャッシュ・フローを12か月分に年換算して比率を計算します。試算表の純資産は「資産合計−負債合計」で求めます。
- キャッシュ・フロー計算書は、期首と期末の貸借対照表の増減と損益から間接法で作り、期末の現金及び預金と一致するかを検算して表示します。固定資産の取得は「固定資産の増加＋減価償却費」（売却との純額）です。
- 貸借対照表の科目は名前から区分を自動判定します。違う場合は「科目の分類」で変更できます（全期間に反映）。
- この機能を追加する前に取り込んだ決算書は、貸借対照表が保存されていないため、もう一度取り込んでください。

## 計算のルール

- **実績**：明細の金額を、日付から会計年度・月に振り分けて合計します。
- **締め月**：その年度で明細がある最後の月です。締め月より後の月の実績は未確定として「—」で表示し、0円とはみなしません。
- **予算差異**：実績 − 予算。費用は予算より少ないと有利（緑）、収益・利益は予算より多いと有利（緑）です。
- **達成率・前年比**：比べる元（予算・前年）が0以下のとき、または未設定のときは「—」です。
- **前年同期間**（明細画面）：当年に実績がある月までにそろえて比べます。
- **千円表示**：千円未満を四捨五入します（負の数も絶対値で四捨五入）。負の数は「△」で表示します。
- **資金繰りの下書き**：売上・仕入は設定した月数後に入出金、人件費・経費は当月払い、減価償却費は現金が出ないので除きます。締め月までは実績、それより後は予算を使います。入力済みの欄は変更しません。

## データの保存場所と保護

- データは**この端末・このブラウザの中（ブラウザ内データベース：IndexedDB）**にだけ保存されます。以前の版の保存データ（localStorage）は、初回起動時に自動で移し、元のデータも別名で残します。サーバーには送りません。別の端末・別のブラウザとは共有されません。
- CSV取込、復元、サンプル削除、KPI削除の前に、その時点のデータを端末内に自動でバックアップします（最新10件）。1日1回の自動バックアップもあります。
- 「設定・データ」→「バックアップを書き出す」で、全データをファイル（JSON）に保存できます。別の端末へ移すときもこのファイルを使います。
- 保存データが読み取れない場合も、上書きせずにそのまま書き出せる画面を表示します。

## CSV取込の形式

1行目に見出し、2行目からデータです（UTF-8・Shift_JISのどちらでも読めます）。

```
日付,勘定科目,取引先,金額,摘要
2026/10/25,売上高,青葉商事,1200000,10月分 請求
```

- 見出しは「日付／取引日」「勘定科目／科目」「取引先／補助科目」「金額」「摘要／備考」を自動で認識します。
- 未登録の勘定科目は、取込画面で区分を選んで登録できます。
- 登録済みと同じ行（日付・科目・取引先・金額・摘要が一致）は、既定で取り込みません。

- アイコン：Lucide 0.460.0（unpkg）
- 文字：Noto Sans JP（Google Fonts）

- PDF読み取り：PDF.js 3.11.174（jsDelivr。PDFを取り込むときだけ読み込み）

通信できない環境ではグラフ・アイコン・PDF読み取りが使えませんが、表と入力、CSV取込はそのまま使えます。
