# 請求書一覧

取引先から届いた請求書（PDF・スキャンPDF・写真）を取り込み、AIで読み取って一覧にし、確認・修正してから Excel に書き出すアプリです。
`index.html` の1ファイルで動き、claude.ai の非公開ページ（Artifact）として公開して使います。

## できること

- 1つのPDFに複数の請求書が入っていても、請求書ごとに分けて一覧にします。
  - 請求書の2ページ目以降、表紙（鑑）＋別紙明細書は1件にまとめます。
  - 納品書・作業報告書・メールなど請求書以外のページは、請求額に入れません（「ページの内訳」で確認・変更できます）。
- 横向き・逆さのページは向きを直してから読み直します。
- 読み取った内容を自動で検算し、問題があれば「要確認」にします。
  - 繰越額＝前回請求額−入金額−調整額
  - 今回請求額＝繰越額＋今回買上額（税込）＋その他
  - 消費税額と税率（10％・8％）、税抜＋税＝税込
  - 明細行の合計＝今回買上額
  - 登録番号（T＋13桁）の検査用数字
  - 同じ請求書の二重取込（同じ請求元・同じ番号と金額、または同じ金額と日付）
- 値を手で直すと「手で修正」と表示し、いつでも「AIの値に戻す」ことができます。計算で補った値は「計算した値」と表示します。
- 読めなかった値は空欄（画面では「—」）のままにし、0円にはしません。
- 手書きの書き込み（売・買・差 など）は、印字の金額とは別の欄に記録します。
- Excel には3つのシートを出力します：「請求書一覧」（合計行は SUM 式）、「明細」、「ページの内訳」。

## 保存先とデータの保護

- claude.ai で開いたとき：あなた専用の保存領域（他の閲覧者からは見えない）に自動保存します。
- それ以外で開いたとき：画面の中だけ（閉じると消えます）。画面上部に表示します。
- 「一覧から外す」は削除ではなく、あとで戻せます（請求書・取り込んだファイルとも）。
- 「バックアップ・設定」から全データを JSON で書き出し・読み込みできます。読み込みは「まだないものを追加」だけで、今のデータを上書き・削除しません。
- 同じファイル（名前・ページ数・サイズが同じ）を取り込み済みの場合は、二重計上を防ぐため取り込みません。
- ページの画像は、取り込んだ端末のブラウザ内にだけ保存します（表示用）。

## AI読み取りについて

- claude.ai でこのページを開いたときだけ使えます。初回に「AIの利用」と「画像を送ること」の許可を求められます。
- 利用は開いた人の claude.ai アカウントの利用枠から消費します（このアプリ用の追加の契約・費用はありません）。
- 1ページずつ読み取ります（同時に3ページ）。利用上限などで止まった場合は「続きを読み取る」で残りだけを読みます。
- 個別のページは、詳細画面の「このページを読み直す（高精度）」で、より性能の高いモデルで読み直せます。

## 使用している外部部品

- アイコン：Lucide 0.460.0（unpkg）
- PDF読み取り：PDF.js 3.11.174（cdnjs。PDFを取り込むときだけ読み込み）
- Excel出力：ExcelJS 4.4.0（cdnjs。書き出すときだけ読み込み）
- 文字：Noto Sans JP（Google Fonts）

## デザイン

デジタル庁デザインシステム（テーブル・ファイルアップロード・ボタン・ノティフィケーションバナー・プログレスインジケーター）、Apple Human Interface Guidelines（ボタン、44pt以上の操作領域）、Material Design 3（48dp以上のタッチターゲット、全画面ダイアログ）を参照しています。アイコンは Lucide、左端に色の帯を付けるカードは使っていません。
